# Motor Trip Studio

Hebrew RTL trip planning application with separate customer and administrator entrances.

Customers can manage destinations, itineraries, route maps and trip budgets. Administrators manage customer details and account status from the management area.

Payment and card-saving features are not yet available.

The public cloud-source.zip contains the previous source baseline (20f2723). A matching source package for the current interface has been delivered privately to the owner; public archive replacement is pending explicit approval.
